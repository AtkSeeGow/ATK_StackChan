# ATK StackChan：本機互動原型

跨主機接手先讀 [HANDOFF_5070.md](HANDOFF_5070.md)；下一階段在 192.168.0.100 部署 STT，192.168.0.199 繼續執行主服務。`AGENTS.md` 提供接手入口；私有金鑰、工具、資料與原廠備份不會隨 Git 同步。

主機設定在根目錄 `.env`。目前實測區網 HTTP Wi-Fi（裝置設定 `firmware/DisplayProbe/network.dev.h`），管理網頁維持 localhost；USB 模式仍保留。正式 HTTPS 設定使用 `network.local.h`，遠端部署尚未驗證。完整欄位與搬移方式見 [CONFIGURATION.md](CONFIGURATION.md)。

第一階段已完成網頁角色對話、番茄鐘、手動在席與離席策略、StackChan 的 USB 表情／計時同步，以及 USB 相機預覽與初步在席判斷。語音與主動自言自語尚未接入。

## 開啟

語音硬體回放已可用；下一階段五秒按鈕收音與 Server 轉文字程式已加入，Server 尚待啟動，見 [SPEECH_SETUP.md](SPEECH_SETUP.md)。

需要 Node.js 24 以上，不需安裝 npm 套件。USB 同步另使用 Python 與 pyserial（此電腦已備妥）。在此資料夾執行：

```powershell
node server.mjs
```

或在 PowerShell 執行 `./start.ps1`。保持執行視窗開啟，瀏覽 http://127.0.0.1:3000 。按 Ctrl+C 停止。關閉網頁不會停止後端計時。

預設連接 `http://192.168.0.100:11434` 的 `qwen3.5:4b`，可在「陪伴設定 → 模型連線設定」修改。後端僅監聽本機，不會修改 Server 設定、安裝模型或呼叫雲端 API。

## 操作規則

- 初始為專注 25 分鐘、休息 5 分鐘，可修改。每段結束後手動切換並開始下一段，不自動連續計時。
- 開始、暫停、繼續、重設由後端處理。重設放棄本段進度，不計入完成輪數。
- 專注完整結束才計入今日輪數，日期以 Asia/Taipei 的完成時間計算。
- 離席策略：繼續、立即暫停，或延遲指定秒數後暫停。回來後需手動繼續；未知狀態不當作離席。
- 修改時長不改動已開始或暫停的這段；下一段或重設後套用。離席策略修改立即生效，已暫停的計時不會自動繼續。
- 重新整理會恢復後端狀態。服務重啟後依原截止時間結算；服務停機期間無法知道真實在席變化，只沿用最後手動狀態。主機時間變動可能影響截止時間。
- 模型沒有實際觀察相機，也不能操作計時；回覆僅為文字與有限表情。提示限制無法保證每句都沒有幻覺。
- 對話最多送最近 12 則及目前狀態給模型，使用 4096 tokens 上下文。單一對話請求依序處理，逾時 150 秒；冷啟動可能較久，模型使用後保留載入 30 分鐘。
- 模型成功回應後才將一組對話保存；失敗的輸入留在網頁輸入框，不新增紀錄。頁面顯示最近 100 則。

## 資料與限制

SQLite 存於 `data/stackchan.sqlite`，包含設定、計時、完成輪數及完整成功對話。首版沒有自動刪除或跨日摘要，資料保留在本機；不是備份方案。先停止服務再備份整個 `data/` 資料夾。

尚未提供手機／區網存取、語音或主動發言。本機後端限制 Host 與 Origin，網頁透過後端呼叫 Ollama，不需更改 Ollama CORS。

## StackChan USB 同步

裝置目前使用 USB 同步韌體。保持 USB 資料線連接；後端會自動啟動橋接、每秒傳送倒數與狀態，並依裝置回覆顯示「已連線」。裝置顯示 FOCUS/BREAK、idle/running/paused/completed、倒數、在席狀態與角色表情；尚未顯示完整中文台詞。

裝置 5 秒未收到資料即顯示 USB DISCONNECTED 與 `--:--`，不自行控制主機計時。重連時只套用最新狀態。關閉服務或拔除 USB 不會直接判定離席；相機來源逾時會變成未知。

- 預設序列埠 COM4；可透過 `STACKCHAN_SERIAL_PORT` 環境變數修改，設為 `off` 可停用 USB 同步。
- `STACKCHAN_PYTHON` 可指定 Python 執行檔；預設使用此電腦 Codex bundled Python。需將 pyserial 安裝於 `.tools/python`（目前已安裝 3.5）。
- 刷機前請先停止本機服務，釋放 COM 埠；刷入後確認裝置正常啟動。必要時短按 RST，不要長按進下載模式。
- 橋接工具自動重連，不自動刷機、下載模型或開啟馬達。喇叭尚未啟用。
- 此輪已實測裝置回覆與網頁的 running、paused、idle 及剩餘時間相符，測試後恢復 25:00 待機。
